# DayDeck

Windows 11용 할 일, 달력 일정, 메모, 알림 관리 프로그램 (트레이 상주, 저메모리).

- 설계 문서: [docs/DESIGN.md](docs/DESIGN.md)
- 예상 화면: [docs/mockups](docs/mockups)
- Microsoft Store 등록: [docs/STORE.md](docs/STORE.md)

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| M1 뼈대 | 솔루션 구조, SQLite/마이그레이션, 설정, 트레이 아이콘, 단일 인스턴스, 자동 실행 | ✅ |
| M2 할 일 | 목록/할 일, 스마트 목록, 완료 표시, 자동 저장 | ✅ |
| M3 알림 | 알림 엔진, 알림 팝업, 놓친 알림, 일일 브리핑, 일시 중지 | ✅ |
| M4 달력 | 월/주/일/목록 뷰, 종일/시간 일정, 드래그 편집, 반복, 한국 공휴일 | ✅ |
| M5 메모 | 폴더 트리, 탭 편집기, 세션 복원, 자동 저장, 검색, 휴지통, 할 일로 만들기 | ✅ |
| M6 빠른 입력 | 전역 단축키, 한국어 자연어 파서(126개 문장 테스트), 빠른 추가 창 | ✅ |
| M7 부가 기능 | 전체 검색(Ctrl+K), 매일 자동 백업(zip), ICS 가져오기/내보내기, CSV 내보내기, 다크 모드, 통합 휴지통 | ✅ |
| M8 확장 | 바탕화면 위젯, 스티커 메모 (뽀모도로·습관·통계는 0.5.0에서 제거) | ✅ |

## 실행 파일 받기

[Releases](https://github.com/aydenchoi/DayDeck/releases)에서 최신 버전을 내려받습니다
(GitHub Actions의 `build` 워크플로 실행 결과에서도 받을 수 있습니다).

- `DayDeck-<버전>-setup.exe`: **설치 프로그램 (권장).** 설치할 폴더를 고를 수 있고, **그 폴더 안의 `Data`가 데이터 폴더**가 됩니다.
  기본은 "나만 설치"(관리자 권한 필요 없음, `%LOCALAPPDATA%\Programs\DayDeck`)이고, 시작 메뉴 바로 가기를 만듭니다.
  제거할 때 데이터도 지울지 묻습니다 (기본: 남김). 아직 코드 서명을 하지 않아 처음 실행할 때 SmartScreen 경고가 나올 수 있습니다 ("추가 정보" → "실행").
- `DayDeck-<버전>-x64.zip`: 설치 없이 쓰는 단독 실행형 `DayDeck.exe` (약 131MB. 빠른 시작과 적은 메모리를 위해 압축하지 않음)
- `DayDeck-<버전>-x64-framework-dependent.zip`: 작은 실행 파일 (약 3MB, [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) 필요)

CI 실행 결과의 `ui-screenshots`에서 각 화면의 스크린샷도 볼 수 있습니다.

**자동 업데이트**: 하루 한 번 새 버전을 확인해 바뀐 점과 함께 묻습니다. **"지금 업데이트"를 눌러야만** 내려받아(SHA-256 확인)
데이터를 백업하고 exe를 바꾼 뒤 다시 시작합니다. `Data` 폴더는 그대로입니다. "나중에", "이 버전 건너뛰기"도 고를 수 있고,
설정 → 업데이트에서 자동 확인을 끄거나 "지금 확인", 트레이 메뉴의 "업데이트 확인"으로 직접 확인합니다.
exe가 쓰기 금지 폴더(예: Program Files)에 있으면 릴리스 페이지에서 직접 받아 바꿔 주세요.

실행하면 트레이에 아이콘이 생깁니다. 어디서나 **Ctrl+Alt+Space**로 빠른 추가 창을 열어 "내일 오후 3시 치과 #개인 !높음 30분 전 알림"처럼
한 줄로 할 일과 일정을 넣을 수 있습니다. 메인 창에서 **Ctrl+K**는 할 일·일정·메모 전체 검색, **Ctrl+1~5**는 화면 이동입니다 (`DayDeck.exe --quick-add`로도 열림. 단축키는 설정에서 변경). 창의 X 버튼은 트레이로 숨기고, 완전히 끝내려면 트레이 아이콘 오른쪽 클릭 → **종료**를 누릅니다.

### 그 밖의 기능

- 집중(뽀모도로)·습관·통계는 0.5.0에서 메뉴와 트레이에서 뺐습니다. 예전 습관·집중 기록은 data.db에 그대로 남아 있습니다.
- **바탕화면 위젯**: 설정 → 화면 또는 트레이 메뉴에서 켭니다. 오늘 할 일을 바로 체크할 수 있습니다.
- **반복 할 일**: 상세 패널의 "반복"이나 빠른 추가의 "매주 금요일까지 주간보고". 완료하면 다음 회차가 새 할 일로 생깁니다 (제목·태그·알림·하위 할 일 유지).
- **태그**: 상세 패널에 쉼표로, 빠른 추가에서는 `@태그`. 왼쪽 메뉴의 "태그"에서 모아 봅니다.
- **예정·기한 지남·완료됨 기간**: 화면 오른쪽 위에서 7일 / 14일을 고릅니다 (기본 7일). 기간보다 오래된 기한 지남은 머리글에 개수로 알립니다.
- **끌어다 놓기**: 할 일을 왼쪽 메뉴의 목록(옮기기)·오늘·태그·완료됨에 놓을 수 있고, 목록을 "직접 정렬"로 바꾸면 끌어서 순서를 바꿉니다.
- **트레이**: 아이콘을 누르면 "오늘" 팝업(바로 체크), 두 번 누르면 메인 창. 오른쪽 메뉴에도 오늘 할 일이 나옵니다 (설정에서 클릭 동작 변경).
- **달력**: 주/일 보기 옆 미니 달력(창이 넓을 때), 음력 표시(설정), 근무 시간 밖은 옅게.
- **Ctrl+Z**: 입력란 밖에서 방금 한 삭제·완료·옮기기를 되돌립니다.
- **메모 서식**: 굵게(Ctrl+B)·기울임(Ctrl+I)·밑줄(Ctrl+U)·취소선·형광펜·글자색·코드, 링크(Ctrl+K), 제목, 글머리/번호/체크 목록, 인용.
  메모는 마크다운(.md) 파일 그대로 저장되어 VS Code·Obsidian 같은 다른 편집기에서도 열립니다
  (글자색·밑줄·형광펜은 마크다운에 없어 `<span style="color:…">`, `<u>`, `<mark>` 태그로 저장).
  메모는 **"보기"로 열리고 서식이 적용된 모양 그대로 바로 고칩니다** (워드처럼: 목록에서 Enter는 다음 항목, 빈 항목에서 Enter는 목록 끝,
  줄 맨 앞에서 `- `·`1. `·`[] `·`# `·`> `를 치면 목록·번호·체크·제목·인용, 체크 상자 클릭, 링크는 Ctrl+클릭).
  마크다운 원문은 **"편집"**(또는 원문과 미리보기를 함께 보는 "나란히")을 직접 눌렀을 때만 보입니다. .txt 메모는 오른쪽 클릭 → ".md로 바꾸기".
  할 일 메모도 메모 화면처럼 "보기"에서 바로 고칩니다 (아래 "할 일 상세"). 일정 편집 창의 메모에는 같은 서식 도구와 미리보기가 있습니다.
- **할 일 상세**: 할 일 목록에서 할 일을 누르면 목록은 왼쪽에 그대로 있고, 오른쪽 전체에 상세가 열립니다.
  위는 제목과 "할 일 정보"(마감·우선순위·목록·반복·태그·알림·하위 할 일, ▾를 눌러 접으면 한 줄 요약), 아래는 넓은 메모입니다.
  메모는 서식이 적용된 모양 그대로 고치고(목록·체크·굵게·표 붙여 넣기 등), "원문"을 누르면 마크다운으로 고칩니다. Esc나 ✕로 닫습니다.
- **메모에 그림**: 화면 캡처 등을 복사해서 편집기에 **Ctrl+V**, 서식 도구의 🖼 단추로 파일 고르기, 또는 그림 파일을 편집기로 끌어다 놓기.
  그림은 메모와 같은 폴더의 `.images\`에 저장되고 메모에는 `![](.images/…png)`로 들어가 "나란히"/"보기"에서 보입니다 (누르면 크게 보기).
  "보기"에서 그림을 누르면 모서리 손잡이를 끌어 크기를 바꿀 수 있고(비율 유지), 너비는 `![|300](.images/…png)`처럼 저장됩니다.
- **주간업무보고**: 왼쪽 메뉴 📋. 제목과 금주실적·차주계획 날짜는 주차에서 자동으로 정해지고(목요일 기준: 그 주 목요일이 있는 달의 몇째 주),
  두 내용만 쓰면 자동 저장됩니다. ◀ 지난주 / 이번 주 / 다음 주 ▶, 날짜 고르기로 이동하고, 저장된 보고는 왼쪽 목록에서 다시 열어 고칩니다.
  **📋 복사**를 누르면 보고 전체가 양식 그대로 클립보드에 들어갑니다. 새 주를 열면 지난주 차주계획을 금주실적에 미리 넣어 줍니다.
  보고는 메모 폴더의 `주간업무보고\연도6-10 5주차.txt`로 저장되어 메모 검색·기록·백업도 그대로 됩니다.
- **표 붙여 넣기·고치기**: 엑셀·구글 시트·워드의 표를 복사해 Ctrl+V 하면 마크다운 표로 들어가 테두리 있는 표로 보입니다 (숫자 칸은 오른쪽 정렬).
  "보기"에서 칸을 누르면 그 자리에서 고칩니다: Tab/Shift+Tab 다음/앞 칸, Enter 아래 칸, Shift+Enter 칸 안 줄바꿈.
  칸에는 그 칸의 마크다운이 보입니다(`**굵게**` 등 서식 기호 그대로). Esc를 누르면 표 전체가 선택되어 Delete로 지우거나 Ctrl+C로 복사하고,
  표를 고른 채 Enter(또는 F2)를 누르면 첫 칸부터 고칩니다. 표 밖으로 나가면 한 번에 반영되어 Ctrl+Z 한 번에 되돌립니다.
- **메모 목록**: 폴더를 누르면 그 폴더와 하위 폴더의 메모가 모두 보이고(고정 → 최근 수정 순), 제목 위에 폴더 위치("메모 › 업무 › 회의록")가 작게 보입니다.
- **폴더 옮기기**: 메모 폴더를 끌어 다른 폴더(또는 최상위 "메모")에 놓으면 그 안으로 옮깁니다.
- **메모 기록**: 자동 저장할 때 10분에 한 번씩 예전 내용을 `Notes\.history\`에 남깁니다 (메모마다 최근 30개).
  도구 모음의 **🕘 기록**에서 버전을 보고 되돌립니다. 되돌려도 지금 내용이 기록에 남아 다시 돌아올 수 있습니다.
- **단축키 켜기/끄기**: 다른 프로그램과 겹치면 설정 → 단축키에서 전역 단축키를 하나씩 끄거나, 메모 서식 단축키(Ctrl+B 등)와
  Ctrl+V 그림 붙여 넣기를 끌 수 있습니다. 서식 단축키를 끄면 메모에서도 Ctrl+K는 전체 검색입니다.
- **화면 배치**: 탐색 메뉴, 할 일 목록(상세를 열었을 때), 메모의 폴더·목록·미리보기 경계선을 마우스로 끌어 너비를 바꿉니다 (두 번 누르면 처음 너비).
  바꾼 너비와 메인 창 위치·크기(최대화 포함)는 데이터 폴더에 저장되어 다음에 열 때 그대로입니다. 설정 → 화면 → "처음 배치로 되돌리기".
- **글자 크기**: 기본 16pt. 설정 → 화면에서 바꾸면 모든 창이 그 크기에 맞춰 커지거나 작아집니다 (화면보다 커지지는 않음).
- **스티커 메모**: 트레이 → "새 스티커 메모" 또는 메모 화면의 "📌 스티커로". 내용은 메모 폴더의 파일 그대로이고, 위치와 색은 다음 실행 때 그대로 다시 뜹니다.

### 데이터 위치와 다른 PC로 옮기기

설정, 할 일/일정 DB, 메모, 백업은 모두 **실행 파일(exe) 옆의 `Data` 폴더 하나**에 저장됩니다.
설치 프로그램을 썼다면 설치할 때 고른 폴더 안의 `Data`입니다.

```
DayDeck.exe
Data\
  settings.json   설정 (글꼴, 테마, 단축키 등)
  data.db         할 일, 일정, 알림, 습관 (단일 파일)
  Notes\          메모 (폴더별 .md / .txt, 그림은 각 폴더의 .images\, 예전 버전은 .history\)
  Backups\        자동 백업 (하루 한 번 zip, 최근 14개. 앱을 끄고 Data 폴더에 풀면 그대로 복원. 설정에서 위치 변경 가능)
  Logs\           오류 기록
```

다른 PC로 옮기려면 트레이 아이콘에서 **종료**한 뒤 `DayDeck.exe`와 `Data` 폴더를 함께 복사하면 됩니다 (USB에 넣어 다녀도 됩니다).
(설정 → 데이터 → **열기**로 폴더를 바로 열 수 있습니다.)

- 실행 파일 폴더에 쓸 수 없는 곳(예: `C:\Program Files`)에 exe만 복사해 두면 대신 `%APPDATA%\DayDeck`에 저장합니다.
  설치 프로그램으로 "모든 사용자용"(Program Files)에 설치하면 `Data` 폴더에 쓰기 권한을 주므로 설치 폴더의 `Data`를 그대로 씁니다.

## 개발

필요: [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0), Windows 10/11 (실행), Visual Studio 2026 또는 Rider (선택)

```powershell
dotnet test                                   # Core 단위 테스트
dotnet run --project src/DayDeck.App       # 실행
dotnet publish src/DayDeck.App -p:PublishProfile=win-x64   # artifacts\publish\win-x64\DayDeck.exe
```

새 버전 내기: `Directory.Build.props`의 `<Version>`을 올리고 `CHANGELOG.md`에 그 버전 구역을 쓴 뒤 main에 머지하면,
CI가 테스트를 통과한 뒤 릴리스 `v버전`(zip 2개 + `SHA256SUMS.txt`)을 만듭니다. 버전이 그대로면 릴리스를 만들지 않습니다.

```
src/DayDeck.Core/    UI와 무관한 로직 (설정, DB, 파일 저장) — 단위 테스트 대상
src/DayDeck.App/     WPF 앱 (트레이, 창, 화면)
tests/                  단위 테스트
tools/DayDeck.DevSeed/  샘플 할 일을 데이터 폴더에 넣는 개발용 도구
scripts/smoke-test.ps1  게시된 exe를 트레이 모드로 실행해 확인 (CI)
scripts/ui-test.ps1     샘플 데이터로 실행해 UI 자동화로 화면을 조작·검사하고 스크린샷 저장 (CI)
```
